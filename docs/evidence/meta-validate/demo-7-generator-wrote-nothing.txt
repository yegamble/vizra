
########## DEMO 7 — a generator that exits 0 without writing (verifier FINDING 1) ##########

BASE SHA: 4b2269043831548b91f00201b494fc53c7673769

Before this fix, check-generated-ledger.sh asserted `git diff --exit-code`
but never that the declared files were WRITTEN. A gutted build.py therefore
printed 'reproduces byte-for-byte' while nothing had been regenerated.
The declared files are now REMOVED before regenerating, so a generator that
writes nothing leaves a deletion the existence check names.
