## Why this file exists

Three review rounds on this PR found the same defect in different clothes:
a checker that matches TEXT, described in this repository's own documents
with a guarantee word — *enforce*, *refuse*, *cannot*, *never*, *every*,
*both directions*, *invoke*, *prove*, *by construction*. The topology was
sound each time; the sentences around it were stronger than the code.

So every such sentence on an operator-facing or CI-facing surface is
audited here: where it lives, what turns it red, and — the column that
matters — **what it does not guarantee**. A sentence with no demonstration
is either softened to what is true or removed; the ones that were are
listed at the end.

Surfaces audited: `docs/META_REPO.md` §2a; `docs/quality/COMMANDS.md`
§4–§8; the docstrings and printed banners of `check-compose-topology.py`,
`check-config-coverage.py`, `check-template-claims.py` and
`compose-render.py`; `README.md`'s operator section; and
`env/production.env.example`'s comments about what tooling does.

What is deliberately **not** audited, as a decision rather than an
omission: the text of a violation message (printed only after its rule has
already fired); narrative about a defect that was fixed (its evidence is
the case that keeps it fixed, audited on its own row); and a claim about
another repository's behaviour, which is marked *not ours* with the
artefact it rests on rather than dressed up as something this lane proves.

## Legend

- **demonstrated** — a `demo.sh` case turns it red
- **code-only** — a real rule, but no case has seen it fire
- **not ours** — a claim about another component or tool
- **no mechanism** — true of the artefact; nothing enforces it

## Known weak spots this file does not fix

Recorded because a claims audit that only lists what was fixed is the
same failure one level up.

- **The disclosure rules match a marker string.** Stripping the `curl`
  commands while leaving the heading passes. The verifier measured this
  at `9c4b5d3` and it is still true.
- **`profile-not-enumerated` reads only compose files some shape lists.**
  A new `docker-compose.*.yml` that no shape loads is read by neither it
  nor any rendered model.
- **An unflagged credential is written raw** into the uploaded artifact
  (S-6). Stated, not fixed: widening the suffix heuristic would train
  people to add exceptions, and the component's own flag is meant to be
  the control.
- **The `secret` flag is validated only locally.** `--drift` needs the
  component checkouts and cannot run in this repository's CI.
- **`scripts/ci-required-guard.sh` (lines 80, 249, 348, 423, 440) and
  `scripts/ci-required-select.sh` (line 56)** still read captured output
  through `printf … | grep -q` under `set -o pipefail` — the same race
  removed from `demo.sh` this round. They are outside this slice's diff
  and are recorded here as a follow-up rather than edited alongside the
  thing they guard.
