## Implementation (search, PR #6)
- `scripts/ci-required-guard.py`: `--base-manifest`; `read_manifest`/`check_tombstones`. Format
  `# tombstone: <lane> retired <YYYY-MM-DD> because <reason>`. Rejects: removal/comment-out without tombstone,
  malformed (no date/no reason), never-existed lane, still-required lane, floor lane, deleted tombstone.
- `scripts/ci-required-guard.sh`: base SHA from `CI_REQUIRED_BASE_SHA` else `git merge-base HEAD origin/main`;
  non-hex → fail; missing commit → `git fetch --depth=1 origin <sha>`; any failure → `BASE MANIFEST UNAVAILABLE`, exit 1.
  Shallow checkout: depth 1 is kept; the base commit is fetched by SHA (checkout persists the token).
- `.github/workflows/ci-required.yml`: `CI_REQUIRED_BASE_SHA: pull_request.base.sha || merge_group.base_sha`.
- `.github/required-checks.txt`: rule documented in header.
- Tests (scripts/scripts_test.go, `test` lane): TestRemovingAManifestLaneNeedsATombstone (7 red + 1 green),
  TestTheShellGuardFailsClosedWithoutABaseManifest (no git, unknown SHA). RED before implementation (both FAIL), GREEN after.
