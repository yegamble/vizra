## Design
- `scripts/bundle-contents.json`: include list, exclude list, release-contract `required` items, `not_yet_shipped` (reason per item), `generated_bind_sources`.
- `scripts/bundle.py` (+ `make-bundle.sh`, `check-bundle.sh` wrappers): Python tarfile/gzip for byte-identity independent of GNU vs BSD tar: sorted entries, USTAR, mtime = SOURCE_DATE_EPOCH (default: HEAD commit time), uid/gid 0, empty owner names, gzip mtime 0 and no name.
- Schema version: migrations live in vizra-core. `MANIFEST.json.schema_version` = highest numeric prefix of `*.up.sql` in `--core-migrations DIR` (a core checkout at the pinned tag), or `components.vizra-core.schema_version` from `--release-record releases/<tag>.json`. CI uses fixtures under `tests/bundle/fixtures/`.
- Check: unpack to an empty dir, reject unsafe entries, verify sha256s and no unlisted files, assert excludes absent, required items shipped or declared, every bind source in shipped compose files present or declared generated, schema = migrations on disk, render every `production` shape with the bundle's own `compose-render.py` from the unpacked tree.
